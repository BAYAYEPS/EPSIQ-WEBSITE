سياسة الخصوصية

آخر تحديث: 21 شتنبر 2026.

1. موقع epsiq.ma

يعرّف الموقع بتطبيق EPSIQ ووظائفه وطرق الولوج إليه ووسائل التواصل. تصفح الصفحات العامة لا يتطلب إنشاء حساب.

2. التواصل

عند التواصل مع EPSIQ عبر البريد الإلكتروني أو إحدى قنوات الدعم، تُستخدم المعلومات التي تختار إرسالها للرد على طلبك ومتابعته عند الحاجة.

3. البيانات داخل تطبيق Android

EPSIQ أداة مهنية موجهة لأساتذة التربية البدنية والرياضية. تُستخدم بيانات الأقسام والتلاميذ والتتبع والتقويم التي يتم إدخالها أو استيرادها لتوفير الوظائف البيداغوجية التي يطلبها الأستاذ.

يبقى جوهر بيانات العمل البيداغوجي محفوظاً أساساً محلياً على الجهاز لتمكين الاستعمال الميداني دون اعتماد دائم على الإنترنت، بما في ذلك الأقسام والتلاميذ والتتبع والتقويمات والمشاريع والجذاذات والحصائل وملفات التصدير. وتظل بيانات تحليلات استعمال المنتج منفصلة عن هذه السجلات البيداغوجية.

4. خدمة الترخيص والولوج السنوي

بحسب النسخة وقناة التوزيع المستعملة، قد يتصل EPSIQ بخدمة الترخيص الرسمية من أجل تفعيل أو تحديث حق الولوج السنوي.

تعالج هذه الخدمة فقط المعلومات التقنية الضرورية للتفعيل وتدبير الترخيص، مثل رمز الولوج الذي يدخله المستخدم، ومعرّف التثبيت، ومعرّف التطبيق وإصداره، وقناة التوزيع.

لا تتلقى خدمة الترخيص لوائح التلاميذ أو أسماءهم أو رموز مسار أو النقط أو التقويمات أو تتبع الحصص أو مشاريع الحلقات أو الجذاذات أو الحصائل. تبقى المعطيات التربوية منفصلة عن خدمة الترخيص ومحفوظة محلياً على الجهاز، ما لم يختَر المستخدم بنفسه تصديرها.

5. بيانات التلاميذ

يبقى الأستاذ مسؤولاً عن الاستعمال المهني للمعلومات التي يدخلها أو يستوردها في EPSIQ، وعليه احترام القواعد المطبقة داخل مؤسسته وإدارته.

6. تحليلات استعمال المنتج

فقط في إصدارات أو builds EPSIQ التي تكون فيها هذه القياسات مفعلة، يستخدم EPSIQ خدمة PostHog لتحليلات استعمال محدودة للمنتج. مشروع EPSIQ مهيأ على PostHog Cloud EU. راجع سياسة الخصوصية لـ PostHog.

الغرض من هذه القياسات محصور في فهم اعتماد الوظائف الأساسية والتقدم في مسارات عمل الأستاذ الرئيسية، لتحسين سهولة الاستعمال وجودة المنتج. ولا تُستخدم للاستهداف الإعلاني أو لإنشاء ملفات تسويقية للأساتذة أو التلاميذ.

بحسب الحدث، قد تتضمن البيانات المحدودة نوع حدث المنتج، وإصدار التطبيق، ولغة الواجهة، وقناة التوزيع، والسلك التعليمي، والمستوى الدراسي المعياري، والطوابع الزمنية التقنية، ومعرّفاً تقنياً مستعاراً يولده مزود الخدمة. ولا يشتق EPSIQ هذا المعرّف ولا يضبطه انطلاقاً من الأستاذ أو الترخيص أو القسم أو الحلقة أو الحصة أو التلميذ أو مسار أو معرّفات قاعدة البيانات.

لا ترسل تحليلات استعمال المنتج أسماء التلاميذ، أو اسم الأستاذ أو بريده الإلكتروني أو هاتفه، أو معرّفات مسار، أو أسماء الأقسام أو المؤسسات، أو المعرّفات الخام للتلاميذ أو الأقسام أو الحلقات أو الحصص أو قواعد البيانات، أو رموز الترخيص أو رموزه المميزة أو منح الولوج، أو النقط، أو بيانات الحضور القابلة للتعريف، أو البيانات الصحية، أو ملاحظات الأستاذ، أو الملاحظات التشخيصية، أو نصوص مشاريع الحلقات أو الجذاذات أو النصوص البيداغوجية الحرة، أو محتوى صادرات PDF/CSV، أو أسماء الملفات أو المسارات أو URI، أو موقعاً جغرافياً يقدمه EPSIQ.

يعطّل EPSIQ معالجة ملفات الأشخاص، وإثراء الموقع الجغرافي GeoIP، وSession Replay، والالتقاط التلقائي للشاشات أو الأنشطة، والخرائط الحرارية، وWeb Analytics، والتتبع التلقائي للأخطاء.

عندما يكون الجهاز غير متصل، قد يحتفظ SDK التحليلات مؤقتاً بأحداث محدودة ويرسلها عند عودة الاتصال. وهذا الطابور منفصل عن البيانات البيداغوجية لـ EPSIQ ولا يؤثر في سير العمل التعليمي دون اتصال.

تُحتفظ ببيانات التحليلات فقط بالقدر اللازم لأغراض تحسين المنتج ووفق إعدادات الخدمة والمشروع المهيأة.

7. الأمان وتقليل البيانات

يهدف EPSIQ إلى الاقتصار على المعلومات اللازمة للاستعمال البيداغوجي. وعلى المستخدم حماية الولوج إلى جهازه وحفظ ملفات التصدير بطريقة مناسبة.
